# Documentation utilisateur avec installation normale

## Installation

### Rust
Tout d'abbord, il faut installer au moins la version 1.88 de Rust en suivant ce guide d'installation : https://rust-lang.org/fr/tools/install/

### npm et Node.js
Installer npm et Node.js en suivant le guide d'installation : https://kinsta.com/fr/blog/comment-installer-node-js/#comment-installer-nodejs-et-npm-

### Compilation
Commencer par ouvrir un terminal et taper les commandes suivantes dans le terminal :

`git clone https://github.com/TagCopperLight/RoadIA`

`cd RoadIA`

`cargo build --release`
