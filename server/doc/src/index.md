# RoadIA — Backend Documentation

Ce livre documente le backend Rust du projet RoadIA. Il couvre les APIs exposées, le modèle de données de la carte, le moteur de simulation (incluant les modèles de changement de voie LC2013 et les trajets pendulaires) et le système de scoring.

L'objectif de cette documentation est de fournir une vision complète des modules, des structures publiques, et des mécanismes internes (comme la gestion des intersections et le modèle de pollution CO2) pour les développeurs et contributeurs.
